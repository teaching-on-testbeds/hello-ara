## Guide for instructors

If you are using ARA in the classroom, here are a few steps you, as the instructor, should first understake:

1. **Create a project on ARA**. Use this form to request a project: https://forms.gle/frpLBmtTMvNptrEEA
2. **Add users to your project**. Once a project has been created for you, log in to https://portal.arawireless.org/ and from Identity > Users, choose "Create User List". Upload a list of (institutional) email addresses that will be associated with your project, as a plaintext CSV file in the following format:

```
username
student1@example.edu
student2@example.edu
```

Once you have completed these steps, you can onboard your students! You can have them create accounts with the first part of [Hello, ARA: Create an account](https://teaching-on-testbeds.github.io/hello-ara/create-account).


> **Note**: In case your university does not have any compatible login option (not in the Globus Auth list, no institutional Google account), you alternatively have the option to add students one at a time with an email address and password. From Identity > Users, choose "Create User" to add a user using this alternate method. You would then need to distribute the passwords to the students, and you would tell them to use Keystone authentication (not Globus) when logging in to the ARA portal.
